# v1 vs v2 —— `format.py:589-623` 例1（9 字段）多维性能对比

- 脚本：`bench/bench_user_case.py`
- 原始输出：`evidence/user_case_bench_stdout.txt`
- 机器数据：`evidence/user_case_bench.json`
- 机器：AMD64 Family 25 Model 80 / 16 逻辑核 / CPython 3.13.3 / Windows
- 口径：`time.process_time()`，k=8（每次测量 160 万行），reps=7，3 轮交替，取 min，主指标为**比值**
- 数据：`n = 200,000` 行（D5 另跑 1k→1M）

## 1. 案例与 v2 等价实现

v1（`format.py:589-603` 逐字）：`describe` 的 `struct.doc` 9 个字段，其中
`hourH` 用 `#.hour.3.2 + #.hour.3.1`（`#` = 按已定义字段名取位置）。

v2 等义实现 = `examples/flight.json`：

```json
{"name": "flight",
 "input":  {"source": "index"},
 "output": {"shape": "list", "single": false, "filter": false, "post": null, "trace": false},
 "out": {"type": "object", "fields": {
   "hour":  {"type": "list",  "value": "$.5.a"},
   "hourA": {"type": "int64", "value": "$.5.a.1"},
   "hourB": {"type": "int64", "value": "$.5.a.2"},
   "hourC": {"type": "int64", "value": "$.2"},
   "hourD": {"type": "str",   "expr": "`str($.5.a.1) + str(hourB)`"},
   "hourE": {"type": "int64", "expr": "`hourA + hourB`"},
   "hourF": {"type": "int64", "expr": "`$.5.a.2 + $.5.a.1`"},
   "hourG": {"type": "int64", "expr": "`hour[2] + 123`"},
   "hourH": {"type": "int64", "expr": "`hour[3][2] + hour[3][1]`"}}}}
```

字段级映射：

| v1 | v2 | 说明 |
|---|---|---|
| `value: "$.5.a"` + `type: list` | `value: "$.5.a"` + `type: list` | 同 |
| `value: "$.5.a.1"` / `.2` / `"$.2"` | 同键 | 同 |
| `ext: "str($.5.a.1) + str(hourB)"` | `` expr: "`str($.5.a.1) + str(hourB)`" `` | ext → JSONata 表达式，反引号包裹 |
| `ext: "#.hour.3.2 + #.hour.3.1"` | `` expr: "`hour[3][2] + hour[3][1]`" `` | **`#.字段` 变成「已计算字段 + JSONata 数值下标」** |

迁移要点：v1 的 `#.hour.3.2` 是位置引用；v2 里 `hour` 已是本行已算出的字段，
直接写 `` `hour[3][2]` `` 即可，codegen 会把常量下标链折叠成 `_a[3][2]`（见 §6）。

## 11. 结论

1. **正确性**：该案例 v1/v2 在 20 万行上逐行完全相同。
2. **稳态吞吐**：v2 ≈ v1（v2/v1 = 0.981x），v2 ≈ 手写参照的 1.01x。**差距是 2% 量级，
   噪声底 0.95%，属于「同档」而不是「显著更快」**。
3. **真正的差异在别处**：
   - 编译期 **0.38x**（3.52 → 1.34 ms）、`compile()` 次数 2 → 1
   - 生成源码 **0.336x 字符 / 0.791x AST**，人可读性显著更好
   - 字段越多越省（9 字段 0.911x）
   - 大规模时更省（0.93–0.98x）
4. **Cython**：两版加速比相同（0.882x），v2 编译慢 0.96 s。
5. **诚实边界**：绝对 µs/行 跨会话不可比（本项目历史上绝对值漂移过 35–56%），
   只有同进程内比值可引用；单变体 spread 在 6–84% 之间，靠 min-of-reps + 交替轮次压制，
   分辨率上限约 1%。
